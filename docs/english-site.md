# 영문 사이트와 전체 블로그 번역

## 제공 범위

| 한국어 주소 | 영문 주소 | 내용 |
| --- | --- | --- |
| `/` | `/en` | 기존 8개 홈 섹션, 대표 작업, 실제 최신 글, 문의 연결 |
| `/about` | `/en/about` | 소개, 기존 이력·통계, 전문 분야 |
| `/works` | `/en/works` | 원본과 이미지·링크·순서를 공유하는 6개 대표 작업 |
| `/contact` | `/en/contact` | 문의 입력·검증·전송·실패·완료 안내 |
| `/blog` | `/en/blog` | 112편 전체 목록·검색, 시리즈 8개 |
| `/blog/[slug]` | `/en/blog/[slug]` | 112편 제목·요약·본문·표·프롬프트·이미지 설명 |
| `/blog/series/[id]` | `/en/blog/series/[id]` | 시리즈별 영문 글 목록 |

상단과 모바일 메뉴의 한국어 / EN 링크로 전환한다. 번역된 페이지는 같은 페이지로 왕복하며 쿼리와 앵커를 유지한다. 미번역 페이지의 EN은 영문 홈으로 연결한다. 교육·상세 프로젝트 등 미번역 영역은 한국어 원문임을 링크에 표시한다. 기존 `/fttx-training` 본문은 이미 영어이므로 영어 교육 링크로 안내한다.

## 파일 구성

- `app/(ko)/`: 기존 한국어 페이지를 경로 그룹으로 이동했다. `(ko)`는 공개 URL에 포함되지 않는다. API와 Threads 콜백은 기존 폴더와 주소를 유지한다.
- `app/en/`: 영문 기본 4페이지, 블로그 목록·상세·시리즈와 영문 루트 레이아웃.
- `app/_components/SiteDocument.tsx`: 양쪽에서 공유하는 문서·폰트·인증 제공자·헤더·푸터. 각각 서버 HTML에 `lang="ko"`, `lang="en"`을 출력한다.
- `lib/i18n.ts`: 번역된 경로 목록, 언어 매핑, 검색용 alternate URL.
- `lib/home-copy.ts`, `components/sections/home/`: 홈 번역 및 기본값이 한국어인 locale 속성.
- `lib/english-works.ts`: 원본 `SHOWCASE_WORKS`에 연결한 영문 소개. 새 미번역 작업도 원문 표시로 유지한다.
- `lib/contact-copy.ts`: 문의 양식과 서버 응답 문구. 영어 예산에는 KRW 단위를 표시하고 기존 한국어 선택값을 전송한다.
- `lib/metadata.ts`, `app/sitemap.ts`: 자기 자신을 가리키는 canonical, 상호 ko/en 및 x-default, 영문 사이트맵 항목.

언어별 루트 레이아웃을 분리해 문서 언어를 정확하게 제공하면서 정적 렌더링을 유지한다. 홈·소개·작업 페이지는 정적, 검색 매개변수를 사용하는 문의 페이지는 동적이다. 기존 디자인·로고·데이터를 재사용하며 새 프로덕션 의존성은 추가하지 않았다.

## 문의 전송

기존 `/api/contact`와 Resend를 사용한다. DB 저장 경로는 없다. 관리자 메일이 제공자에게 접수되어 ID를 받은 경우에만 성공을 반환한다. 설정 없음은 503, 제공자 거절은 502로 처리하며 입력은 화면에 유지한다. 관리자 메일 접수 후 자동 확인 메일만 실패하면 접수 성공과 자동회신 실패를 구분해 재제출을 유도하지 않는다. 개인정보 콘솔 출력은 제거했다.

실제 운영 메일 수신·OAuth 로그인·운영 DB 연결은 이번에 검증하지 않았다. 로컬 검증용 프로세스는 임시 인증값, 사용하지 않는 로컬 DB 주소, 비어 있는 메일 키로 운영 연동과 분리했다. 이 설정을 운영 배포 설정으로 사용하면 안 된다.

## 로컬 확인

프로젝트 운영용 환경을 갖춘 일반 개발은 기존 `npm run dev`를 사용한다. 이번 격리 미리보기는 빌드 후 `node output/english-preview.cjs start`로 열며 주소는 `http://127.0.0.1:3100/en`이다. 격리 미리보기에서 문의는 설정 없음으로 실패하는 것이 정상이다.

커밋·푸시·배포는 실행하지 않았다.


## 블로그 112편 영문화 — 2026-09-09

한국어 `content/posts/*.mdx` 112편을 보존하고 `content/posts/en/`에 각각 전체 영문 번역을 추가했다. 템플릿은 공개 글 수에서 제외했다. 원문의 제목·요약·본문·표·목록·이미지 alt와 자연어 프롬프트/체크리스트/코드 설명 주석을 번역했다. 실행 코드와 미디어/링크 URL, 날짜·시리즈·장 번호는 유지했다. 글꼴을 설명하는 실제 문자 예시 ㄱ, 이미지에 이미 포함된 글자, 원본 음원은 그대로다. 원문의 기술·가격·정책 주장을 새 시점에 맞춰 검증하거나 변경하지 않았다.

- `lib/mdx.ts`: locale 기본값 ko. en은 별도 번역 파일을 읽으며 원문이 바뀐 번역은 반환하지 않는다.
- `translationSourceHash`: 원문 UTF-8 텍스트의 CRLF를 LF로 정규화한 SHA-256. Windows/Linux 체크아웃 차이에 영향받지 않는다.
- `scripts/sync-blog-translations.cjs`: 현재 원문과 일치하는 번역만 `lib/blog-translation-index.json`에 등록한다. dev/build 시작 시 자동 실행한다. 새 글은 영어 번역이 준비될 때까지 언어 전환·alternate에 등록하지 않는다.
- `components/mdx/EnglishMDXComponents.tsx`: 이미지·표·오디오 안내 영문화, 실제 영문판이 있는 내부 링크 연결.
- 영문 홈의 최근 글, 상단 Writing, 소개의 저널 링크는 영문 블로그로 연결한다.
- 구독 양식은 영문 UI를 제공하지만 기존 발송 뉴스레터는 한국어임을 안내한다. 설정 없음/제공자 저장 실패를 성공으로 표시하던 기존 API 처리를 수정하고 확인된 구독만 성공으로 반환한다. 실제 이메일은 이번 작업에서 발송하지 않았다.
