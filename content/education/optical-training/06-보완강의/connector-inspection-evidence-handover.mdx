광커넥터 검사 결과를 인계할 때는 합격 표시만 보내지 말고, 어느 단면을 어떤 기준으로 검사했는지 다시 찾을 수 있도록 저장합니다. 맞물리는 플러그와 포트 안쪽 단면을 각각 식별하고, 검사 이미지·판정 기준·촬영 시각을 같은 선로의 손실 기록과 연결하는 방식입니다. 단면 검사 합격은 그 선로 전체의 손실 시험 합격을 뜻하지 않습니다.

2026년 10월 12일 확인한 Fluke Networks 공식 자료 기준입니다. 장비 사례는 FI-3000 사용자 매뉴얼의 March 2019, Rev. 1 7/2019 판본입니다. 현재 앱에서 같은 메뉴가 보인다고 보장하지 않으며, 실제 사용 장비의 매뉴얼과 프로젝트 시방을 먼저 확인합니다. 이 교안의 인계표와 파일 연결 방식은 DMS의 교육용 제안이지 IEC 표준의 의무 항목이 아닙니다.

## 학습 목표

- 맞물리는 두 단면과 케이블의 두 끝을 구분합니다.
- 검사 기준과 기록 전용 결과를 구별합니다.
- 제삼자가 열어 확인할 수 있는 검사 기록 묶음을 구성합니다.

## 1. 합격 화면과 인계 자료

**화면 요점: 단면 이미지에 식별 정보와 판정 조건을 붙입니다.**

강사 설명: 오염 여부를 확인하는 작업과 그 결과를 다음 담당자에게 전달하는 작업은 다릅니다. 현장에서 선명한 이미지를 보았더라도 저장 파일에 포트 이름이 없으면 나중에 같은 단면을 찾기 어렵습니다. 반대로 이름만 정확하고 이미지가 흐리면 검사 내용을 확인할 수 없습니다. 파일을 받는 사람이 촬영 장소와 대상, 적용 기준을 함께 알아볼 수 있어야 인계 자료로 쓸 수 있습니다.

Fluke Networks 백서는 검사 이미지와 합불 결과를 손실 또는 OTDR 기록과 함께 보관하는 방향을 설명합니다. 다만 이미지를 저장했다는 사실만으로 손실 측정 조건까지 확보되는 것은 아닙니다. 단면 검사, 삽입손실 측정, OTDR 시험은 서로 다른 질문에 답하므로 결과를 한 항목으로 합쳐 합격 처리하지 않습니다. 각 시험의 결과와 조건을 남기고 선로 식별자로 연결합니다.

기본 검사·청소 방법은 기존 [커넥터 오염 교안](/education/optical-training/03-connectors-and-contamination)에서, 측정 조건과 원본 파일 관리는 [시험 기록 교안](/education/optical-training/05-test-documentation)에서 이어서 볼 수 있습니다. 이번 교안은 청소 절차를 반복하기보다 단면 검사 결과가 다른 포트의 기록으로 뒤바뀌지 않게 만드는 데 집중합니다.

## 2. 양쪽 단면은 무엇을 뜻합니까?

**화면 요점: 같은 접속점의 플러그·포트와 케이블 끝 A·B는 다른 구분입니다.**

강사 설명: 하나의 접속점에서도 패치코드 플러그 단면과 어댑터 또는 장비 포트 안쪽의 맞은편 단면을 따로 검사합니다. 여기서 양쪽은 서로 맞물리는 접촉면을 말합니다. 선로 반대편에 있는 케이블 끝 A와 B만 촬영하면 한 접속점의 두 접촉면을 모두 확인한 것이 아닙니다. 인계표에는 먼저 장소와 포트를 적고, 그 안에서 어느 부품의 단면인지 구분합니다.

FI-3000 매뉴얼 인쇄 쪽 12의 End 1/End 2는 저장할 때 어느 케이블 끝을 시험했는지 지정하는 항목입니다. 이 값을 플러그와 포트 안쪽이라는 뜻으로 바꾸어 쓰지 않습니다. 장비에 맞물림 부품을 따로 적는 칸이 없다면 인계표의 별도 열이나 승인된 식별 규칙으로 보완합니다. 장비가 제공하지 않는 기능을 제공한다고 가정하지 않습니다.

![케이블 끝 A와 B 각각에서 플러그와 포트 단면을 별도로 식별하는 연결도](/images/education/optical-training/connector-inspection-evidence-handover/identity-ko.svg)

*설명용 연결도입니다. 장비 화면이나 실제 시공 사진이 아니며, 검사 팁의 형상과 광섬유 배열을 나타내지 않습니다.*

## 3. 판정 기준과 기록 전용 결과

**화면 요점: 기준 미확인과 기록 전용은 합격이 아닙니다.**

강사 설명: FI-3000 매뉴얼은 프로젝트 설정에서 작업에 맞는 Test Limit(검사 한계 기준)과 광섬유 수에 맞는 Fiber End Type(단면 유형)을 선택하도록 설명합니다. 저장 전에 작업 대상과 기준 선택이 일치하는지 확인합니다. 이름이 비슷한 프로파일을 선택했다는 이유로 시방을 충족했다고 단정하지 말고, 실제 커넥터와 광섬유 종류, 검사 대상의 배열을 해당 장비 지침과 대조합니다.

같은 매뉴얼 인쇄 쪽 6에는 Document Only(기록 전용)일 때 합격·불합격 상태가 없다고 명시돼 있습니다. 이미지를 보관하기 위한 설정과 기준에 따른 자동 판정은 구분해야 합니다. 기록 전용 이미지를 합격 사진이라고 이름 붙이면 인계자가 하지 않은 판정을 수신자가 했다고 오해할 수 있습니다. 별도 판정이 필요하면 적용 기준과 판정자를 확인한 뒤 결과를 따로 남깁니다.

검사 기준의 이름만으로 표준 판본까지 알 수 없는 경우도 있습니다. 장비 모델과 사용 소프트웨어 버전, 선택한 프로파일 이름을 확인 가능한 범위에서 기록하고, 보고서에 나타나지 않는 값은 별도 조건표에 적습니다. 이 교안은 현행 IEC 61300-3-35 원문의 한계값이나 조항을 검증하지 않았으므로 결함 크기·개수의 합불 수치를 제시하지 않습니다.

| 기록 상태 | 인계 때 남길 내용 | 피할 표현 |
|---|---|---|
| 장비 기준에 따른 합격·불합격 | 선택 기준, 대상, 이미지, 장비 결과 | 전체 선로 합격 |
| 기록 전용 | 이미지, 대상, 기록 전용 표시 | 검사 합격 |
| 기준 또는 대상 미확인 | 누락 조건과 보완 담당 | 확인 완료 |

## 4. MPO 번호와 방향

**화면 요점: 이미지 번호가 실제 광섬유 번호와 맞는지 확인합니다.**

강사 설명: MPO처럼 여러 광섬유가 한 단면에 있는 경우에는 전체 결과뿐 아니라 각 광섬유의 위치를 다시 찾아야 합니다. FI-3000 매뉴얼 인쇄 쪽 13은 검사 팁의 키 위치와 어댑터 종류에 맞춰 Key Position(키 방향)을 설정해야 이미지 번호가 커넥터 번호와 일치한다고 설명합니다. 단순히 화면 왼쪽부터 번호를 붙이는 방식으로 대신하지 않습니다.

그 설명은 해당 장비와 팁, 어댑터 조합에 대한 사용법입니다. 다른 검사기 화면이나 실제 배선의 극성까지 같은 규칙으로 결정할 수는 없습니다. 인계 전에 사용 팁과 어댑터, 번호 방향의 확인 근거를 남기고, 대상 광섬유의 결과를 실제 포트와 연결합니다. 번호 대응이 불명확하면 이미지 자체가 선명하더라도 해당 광섬유의 확정 결과로 넘기지 않습니다.

## 5. 저장과 내보내기 확인

**화면 요점: 저장한 파일을 다시 열어 읽을 수 있는지 확인합니다.**

강사 설명: FI-3000 매뉴얼 인쇄 쪽 15와 17은 검사 결과 요약과 상세 이미지에서 결과를 저장하는 흐름을 설명합니다. 같은 문서 인쇄 쪽 20~21에는 저장 결과를 단면 이미지 또는 PDF 보고서 형태로 내보내는 기능이 있습니다. 이는 기능 설명이며, 고객 자료를 이메일이나 공개 계정으로 보내라는 뜻은 아닙니다. 승인된 내부 보관 위치와 전달 권한을 따릅니다.

내보내기를 누른 다음에는 파일 이름과 실제 내용을 다시 확인합니다. 일부 Android 기기의 공유 이미지가 프로브 이미지보다 낮은 해상도일 수 있다는 매뉴얼 주의가 있으므로, 파일이 생겼다는 사실만으로 판독 가능하다고 처리하지 않습니다. 수신자가 볼 크기에서 단면, 광섬유 번호, 결과와 기준 표시가 읽히는지 살핍니다. 필요한 정보가 빠졌으면 원본 저장 결과를 보존하고 적절한 내보내기 방식이나 별도 조건표로 보완합니다.

DMS가 제안하는 연결 키는 장소·패널·포트·케이블 ID·광섬유 번호·케이블 끝·맞물림 부품·검사 시각입니다. FI-3000의 Cable ID(케이블 식별자)도 현장 선로 식별 규칙과 맞춰 기록합니다. 모든 값을 긴 파일명 하나에 넣을 필요는 없습니다. 파일 이름에는 찾는 데 필요한 짧은 식별자를 쓰고, 인계표에서 이미지·보고서·손실 기록의 경로를 연결하면 됩니다. 원본 결과를 덮어쓰지 않고 정정 사유와 재검사 시각을 남겨야 어느 결과가 최종본인지 설명할 수 있습니다.

![대상 식별부터 기준 확인, 검사 저장, 내보내기 판독, 인계표 연결까지의 다섯 단계](/images/education/optical-training/connector-inspection-evidence-handover/flow-ko.svg)

*DMS 교육용 기록 흐름입니다. 표준의 의무 순서나 장비의 실제 메뉴 화면이 아닙니다.*

## 6. 가상 인계 사례

**화면 요점: 사진의 수보다 대상과 조건의 대응을 확인합니다.**

강사 설명: 교육용 가상 사례로 패널 P1의 포트 07을 검사했다고 가정합니다. 파일 한 장에 합격 표시가 있지만 맞물림 부품 이름이 비어 있고, 다른 이미지에는 포트 이름만 있습니다. 이 두 장을 같은 접속점의 양쪽 단면이라고 묶기 전에 각각 무엇을 촬영했는지 확인합니다. 실제 촬영 대상을 모르면 파일 이름을 추측해 고쳐 확정하지 않습니다.

두 번째 이미지가 기록 전용이었다면 그 상태를 유지합니다. 자동 합격 이미지와 기록 전용 이미지를 나란히 붙였다고 접속점 전체의 검사가 끝나는 것은 아닙니다. 대상과 기준을 보완하고 필요한 단면을 다시 검사한 뒤 새 시각과 결과를 남깁니다. 손실 기록은 같은 선로 식별자로 연결하되, 광학 시험의 합불은 그 시험의 설정과 시방에 따라 별도로 검토합니다. 이 사례는 실제 고객 현장이나 DMS 수행 이력이 아닙니다.

## 7. 인계 체크리스트

- 장소·패널·포트가 도면 및 선로 기록과 일치합니까?
- 케이블 끝과 맞물림 부품을 서로 다른 항목으로 적었습니까?
- 양쪽 맞물림 단면의 이미지가 각 대상에 연결돼 있습니까?
- 선택 기준·대상 유형·장비·확인 가능한 소프트웨어 버전을 기록했습니까?
- MPO 광섬유 번호 방향을 해당 장비 매뉴얼로 확인했습니까?
- 기록 전용과 합불 판정을 구분했습니까?
- 내보낸 파일에서 필요한 이미지와 문구가 읽힙니까?
- 같은 선로의 손실·OTDR 기록, 재검사 이력과 최종본을 찾을 수 있습니까?

## 8. 확인 문제

1. 케이블 끝 A와 B를 한 번씩 찍으면 같은 접속점의 양쪽 맞물림 단면을 검사한 것입니까?
   - 정답: 아닙니다. 케이블의 두 끝과 한 접속점의 플러그·포트 단면은 다른 구분입니다.
2. FI-3000의 Document Only 결과를 자동 검사 합격으로 인계해도 됩니까?
   - 정답: 안 됩니다. 이 모드에는 합격·불합격 상태가 없으므로 기록 전용이라고 표시합니다.
3. MPO 이미지와 합격 표시가 선명해도 번호 방향을 모르면 무엇을 보완해야 합니까?
   - 정답: 해당 장비의 팁·어댑터·키 설정과 실제 광섬유 번호의 대응을 확인합니다. 번호를 추측하지 않습니다.

- 장비 사용법은 해당 제조사의 확인된 설명이며, 인계표와 연결 키는 DMS 해석입니다. 두 자료는 같은 제조사 자료로 독립된 표준 검증 두 건이 아닙니다. 원문 사진·도표·앱 화면은 복제하지 않았습니다.
- 광커넥터를 직접 들여다보지 않습니다. 눈에 보이지 않는 광이 있을 수 있으므로 현장 광 안전 절차와 장비 매뉴얼을 따릅니다. 이 교안은 실장비 시험 결과나 현행 앱의 동작 검증을 제공하지 않습니다.
