MPO 극성은 채널 끝에서 송신 광섬유가 맞은편 수신 위치에 닿도록 부품을 짝지어 쓰는 약속입니다. 방식(Method)은 채널 전체의 부품 조합을, 형식(Type)은 트렁크·어댑터·코드 같은 개별 부품의 섬유 대응을 가리킵니다. 부품에 적힌 Type A가 곧 방식 A는 아니므로, 채널마다 방식 하나를 정해 끝까지 유지하고 라벨 전체를 방식 표와 대조합니다.

2026년 10월 20일 확인한 자료 기준입니다.

## 학습 목표

- 방식과 형식을 구분합니다.

- 형식별로 위치 1이 도착하는 곳을 읽습니다.

- 발주서와 시험 기록에서 방식이 어긋난 부품을 찾습니다.

## 방식 A와 형식 A는 같은 말입니까?

![방식 A와 형식 A는 같은 말입니까?](/images/education/optical-training/mpo-polarity-method-type-readout/concept-ko.svg)

아닙니다. TIA-568.3-E를 요약한 TIA 광섬유 기술 협의체(FOTC)의 자료는 배열(array) 극성의 표본 방식으로 A, B, C, U1, U2 다섯 가지를 들고, 방식끼리 호환되지 않을 수 있으니 하나를 미리 정해 설치 전체에서 일관되게 쓰라고 권고합니다. 같은 자료에서 형식은 트렁크 케이블, 어댑터, 패치코드, 변환부 각각에 붙는 이름입니다. 방식 A는 Type A 트렁크를 쓰지만 같은 채널의 한쪽 끝에는 Type B 배열 코드가 들어갑니다. 라벨에 Type B가 보인다는 이유만으로 방식 B라고 읽으면 틀릴 수 있습니다.

이름이 겹치는 까닭은 간단합니다. 방식은 채널 설계의 이름이고 형식은 부품 규격의 이름인데 둘 다 A, B, C를 씁니다. 발주서에 Type A 트렁크와 Type B 코드가 함께 적혀 있으면 방식 A의 배열 구성일 수 있고, 같은 Type B가 방식 B의 트렁크를 가리킬 때도 있습니다. 그러니 라벨을 읽을 때는 이 이름이 채널의 이름인지 부품의 이름인지 먼저 묻고, 그다음 부품 목록 전체를 방식 표에 맞춰 봅니다.

이 교안은 문서를 판독하는 교육입니다. TIA-568.3-E 표준 본문은 열람하지 못했고, 표준을 요약한 협의체 자료와 제조사 기술 문서를 서로 대조했습니다. 현장 시험은 승인된 절차와 장비 매뉴얼에 따라 담당자가 수행합니다. 포트를 직접 들여다보며 송신 쪽을 찾는 일은 하지 않습니다.

- 방식: 채널 전체의 부품 조합

- 형식: 부품 하나의 섬유 대응

- 라벨의 Type A ≠ 방식 A

## 위치 1은 어디에 도착합니까?

형식 A는 1번이 1번에, 형식 B는 1번이 12번에, 형식 C는 인접한 두 섬유를 맞바꿔 1번이 2번에 도착합니다. Fluke Networks의 2025년 11월 12일 문서는 이 세 대응을 12심 MPO 기준으로 설명합니다. Type A 트렁크는 한쪽 끝을 키 위, 다른 쪽을 키 아래로 만들어 위치 1의 섬유가 반대편 위치 1에 닿습니다. Type B 트렁크는 양쪽이 키 위이고 1번이 12번에 닿습니다. Type C 트렁크는 안에서 섬유 쌍을 바꿔 1번이 2번에, 2번이 1번에 닿습니다. 키는 커넥터 윗면의 돌기이고 옆면의 흰 점이 위치 1을 나타냅니다.

![형식 A·B·C의 위치 대응](/images/education/optical-training/mpo-polarity-method-type-readout/positions-ko.svg)

| 형식 | 트렁크 양끝 키 | 12심 위치 대응 | 읽는 법 |
| --- | --- | --- | --- |
| Type A | 위 / 아래 | 1→1, 2→2 … 12→12 | 직선 |
| Type B | 위 / 위 | 1→12, 2→11 … 12→1 | 역순 |
| Type C | 위 / 아래 | 1→2, 2→1, 3→4, 4→3 … | 쌍 교차 |

이 대응표는 어떤 응용에 쓸 수 있는지 걸러 낼 때 바로 쓸모가 있습니다. 같은 Fluke 문서에 따르면 8심 병렬 응용은 위치 1–4로 송신하고 위치 9–12로 수신합니다. 송신 1번이 맞은편 수신 12번에 닿아야 하므로 역순 대응이 맞고, 직선 대응만 있으면 송신이 송신에 닿습니다. 쌍을 바꾸는 형식 C에서는 1번이 2번, 곧 같은 송신 쪽 위치로 가서 맞지 않습니다. Fluke가 형식 C 트렁크를 병렬 응용에 권하지 않는 이유와 이어지는 대목이며, 이 표를 이렇게 읽는 것은 DMS의 해석입니다. 실제 모듈의 송수신 배치는 장비 사양서로 확인합니다.

듀플렉스 응용은 반대로 읽습니다. Fluke 문서의 듀플렉스 예에서 위치 1은 송신이고 위치 2는 수신이므로, 쌍을 교차하는 형식 C는 케이블 안에서 이미 송신을 수신에 연결합니다. 형식 A는 1번이 1번에 닿아 송신이 송신으로 가기 때문에 어딘가에서 한 번 더 바꿔 주어야 하고, 방식 A에서는 한쪽 끝의 A-A 듀플렉스 코드가 그 일을 맡습니다.

- 형식 A: 1→1 직선

- 형식 B: 1→12 역순

- 형식 C: 1→2 쌍 교차

## 방식마다 어떤 부품을 함께 씁니까?

방식마다 트렁크·어댑터·변환부·코드의 조합이 정해져 있고, 다른 방식의 부품을 섞어서는 안 됩니다. TIA FOTC의 요약은 다섯 방식을 다음처럼 정리합니다. 듀플렉스 구성은 MPO-LC 변환부를 쓰는 경우이고, 배열 구성은 MPO끼리 잇는 경우입니다.

| 방식 | 트렁크 | 어댑터 | 듀플렉스 구성 | 배열(MPO-MPO) 구성 |
| --- | --- | --- | --- | --- |
| A | Type A | Type A, 키 위/아래 | 변환부 Type A, 한쪽 A-B 코드와 다른 쪽 A-A 코드 | 배열 코드 Type A 한쪽, Type B 다른 쪽 |
| B | Type B | Type B, 키 위/위 | 변환부 Type A, 양쪽 A-B 코드 | 배열 코드 Type B 양쪽 |
| C | Type C | Type A, 키 위/아래 | 변환부 Type A, 양쪽 A-B 코드 | 배열 코드 Type B 한쪽, Type C 다른 쪽 |
| U1 | Type B | Type A, 키 위/아래 | 변환부 Type U1, 양쪽 A-B 코드 | 설명 없음 |
| U2 | Type B | Type B, 키 위/위 | 변환부 Type U2, 양쪽 A-B 코드 | 설명 없음 |

표에서 눈에 띄는 점은 세 가지입니다. 먼저 방식 A는 양쪽 끝 코드가 서로 다릅니다. Fluke는 이 때문에 접속 구역에서 혼동이 생기고 두 종류의 코드를 모두 재고로 관리해야 한다고 설명합니다. 다음으로 방식 B는 양쪽 코드가 같아 선택이 단순하지만, 같은 문서에 따르면 보통 한쪽 변환부를 뒤집어 설치해야 해서 번호 표기가 헷갈리고 별도 라벨이 필요하며, 제조사에 따라서는 양끝에 서로 다른 변환부를 요구합니다. 마지막으로 2022년 9월에 발행된 TIA-568.3-E에서 새로 들어온 U1과 U2는 Type B 트렁크와 A-B 코드를 쓰고, TIA 요약에서는 듀플렉스 구현만 설명됩니다.

U1과 U2의 차이는 변환부 안의 섬유 배치와 어댑터 방향입니다. Siemon은 U1이 키 위/아래 어댑터를 쓰므로 단일모드의 각도 연마(APC) 단면도 받아 줄 수 있다고 설명합니다. Fluke는 U2가 고속 병렬 포트에서 여러 듀플렉스 포트로 바로 나누는 직접 분기를 지원하고, U1로 같은 분기를 하려면 비표준 A-A 코드가 더 필요하다고 설명합니다. 이 장점은 제조사 설명이므로 선택하기 전에 해당 제품의 사양서로 다시 확인합니다.

- 방식 하나의 표 안에서만 부품 선택

- 듀플렉스 구성과 배열 구성 구분

- U1·U2: 듀플렉스 전용으로 설명됨

## 자료마다 설명이 다르면 무엇을 따릅니까?

설명이 어긋나면 표준 요약과 제조사 문서의 적용 조건을 나누어 읽고, 확인되지 않은 쪽은 판단을 보류합니다. 이번에 대조한 자료에서 어긋나 보이는 대목이 세 군데 있었습니다.

첫째, 방식 A의 코드입니다. Fluke의 2025년 11월 문서는 한쪽 끝에 A-A 듀플렉스 코드가 필요하다고 쓰고, 2026년 1월 문서는 한쪽에 Type A 배열 코드, 다른 쪽에 Type B 배열 코드를 쓴다고 씁니다. 두 문장은 충돌하지 않습니다. 앞의 것은 MPO-LC 변환부를 쓰는 듀플렉스 구성이고, 뒤의 것은 MPO끼리 잇는 배열 구성입니다. TIA 요약이 두 구현을 따로 적은 것과 맞습니다. 코드라는 단어를 만나면 LC 듀플렉스 코드인지 MPO 배열 코드인지부터 확인합니다.

둘째, U2의 변환부 이름입니다. Fluke의 2025년 11월 문서는 U2 설명에서 Type U1 변환부를 적었지만, TIA FOTC·Siemon·CommScope의 설명은 Type U2 변환부입니다. 이 교안은 세 곳의 설명을 따르고 Fluke 문장은 불일치로 기록합니다. 오기인지 다른 뜻인지는 확인하지 못했습니다.

셋째, 방식 B의 어댑터 방향과 단일모드입니다. TIA 요약은 방식 B의 배열 구성에 키 위/위 어댑터를 적습니다. Fluke의 2025년 11월 문서는 키 위/위 방식이 8도 각도의 APC 단면을 제대로 맞물리지 못한다고 설명하고, 2026년 1월 문서는 APC에서 Type A 어댑터를 쓰는 변형을 수정된 방식 B라고 부릅니다. 같은 문서에서 모든 단일모드 MPO는 APC라고 하므로, 단일모드 채널은 방식 이름만 믿지 말고 어댑터 방향까지 제조사 설계서로 확인합니다.

Fluke의 세 문서는 한 제조사의 자료이므로 독립된 검증 세 건으로 세지 않습니다. 이번 교안의 근거는 표준 요약 한 건과 서로 다른 제조사 세 곳, Fluke의 시험 관점 문서입니다.

- 코드: LC 듀플렉스인지 MPO 배열인지 확인

- U2 변환부 이름: 자료 간 불일치 기록

- 단일모드: 어댑터 방향까지 설계서로 확인

## 가상 발주서는 어디가 어긋났습니까?

방식 A도 방식 B도 아닌 조합입니다. 교육용으로 가정한 12심 발주서에 Type A 트렁크, 양쪽 끝 Type B 배열 코드, Type A 어댑터가 적혀 있다고 하겠습니다. 방식 A는 Type B 코드를 한쪽 끝에만 허용합니다. Fluke의 2026년 1월 문서는 TIA 기준으로 한 링크에 Type B 코드는 하나만 허용된다고 적었습니다. 방식 B라면 트렁크가 Type B여야 하니 이 구성도 아닙니다. Fluke는 트렁크가 Type A인데 양쪽에 Type B 코드를 설치한 실수를 극성 시험기가 잡아 준다고 설명합니다. 이 발주서의 품명과 수량은 모두 가정이며 실제 제품이 아닙니다.

고치는 길은 두 가지입니다. 한쪽 코드를 Type A로 바꾸면 방식 A의 배열 구성이 되고, 트렁크를 Type B로 바꾸면 방식 B가 되지만 이때는 어댑터와 코드도 방식 B 표에 맞춰야 합니다. 어느 쪽이 맞는지는 이미 설치된 장비, 재고, 응용 사양에 따라 설계 담당자가 정합니다. 시험 결과가 극성 불일치를 보여도 곧바로 케이블을 교체하지 말고, 방식 표에서 어떤 부품이 설계와 다른지부터 특정합니다. Fluke는 극성을 설계 단계에서 정해야 하며, 사전 제작된 조립품은 주문 제작이어서 반품이 어려운 경우가 많다고 설명합니다.

핀도 함께 봅니다. Fluke에 따르면 활성 장비의 MPO 포트는 핀이 있는 수컷이어서 장비에 직접 꽂는 케이블은 핀이 없어야 합니다. Siemon이 요약한 TIA-568.3-E 권고는 트렁크를 양끝 핀 있음으로, 변환부 안의 MPO와 이후 장비용 배열 코드를 핀 없음으로 두는 것입니다. 핀 구성이 틀리면 극성이 맞아도 접속이 성립하지 않으므로 극성 표와 같은 줄에 적어 둡니다.

- 방식 A: Type B 코드는 한 링크에 하나

- 방식 B: Type B 트렁크가 전제

- 핀 유무는 극성과 별도 기록

## 인계 기록과 확인 한계

인계 자료에는 방식 이름, 부품별 형식, 어댑터 방향, 양끝의 핀 유무, 섬유 수(8심 또는 12심), 연마(UPC 또는 APC), 기대 위치 대응과 시험기 결과를 한 장에 적습니다. 기대 대응은 예를 들어 송신 1번이 수신 12번에 닿는다는 식으로 먼저 쓰고, 시험기가 보여 준 대응과 나란히 놓습니다. 시험기의 모델과 소프트웨어 판본도 함께 남깁니다. Fluke는 자사 시험기가 코드, 영구 링크, 채널의 극성을 검사할 수 있다고 설명하는데, 이는 제조사 설명이며 이 교안에서 장비를 사용해 재현하지 않았습니다.

현장에서 키 방향을 바꾸는 부품도 있습니다. Fluke는 US Conec의 MTP PRO와 Panduit의 PanMPO가 UPC 다중모드 커넥터에서 키 위치를 바꿀 수 있다고 소개하면서, 각도 단면 때문에 APC 커넥터는 극성을 바꿀 수 없다고 적었습니다. 이런 부품을 쓰면 라벨과 실제 키 방향이 달라질 수 있으므로 변경 사실을 기록에 남깁니다.

확인하지 못한 것은 분명히 적어 둡니다. TIA-568.3-E 표준 본문과 그 이후 개정 여부, IEC 쪽 규격, 제조사 고유의 방식 이름, 실제 시험기 동작은 이 교안에서 확인하지 않았습니다. TIA FOTC와 CommScope의 게시일은 검색 결과에 표시된 날짜이고 본문에는 날짜가 없었습니다. Fluke의 MPO 학습 페이지는 날짜가 표기되어 있지 않았으며 확인일은 2026년 10월 20일입니다. 원문의 그림과 표는 복제하지 않았고 위치 대응은 독자적으로 다시 그렸습니다. 최종 인수 판정에는 해당 규격과 고객 사양에 맞는 시험이 따로 필요합니다.

- 방식·형식·방향·핀·연마를 한 장에

- 기대 대응과 시험기 결과를 나란히

- 미확인 범위를 기록에 명시

- 모든 부품이 같은 방식의 표 안에 있습니까?

- 어댑터 방향과 핀 유무를 양끝 모두 기록했습니까?

- 기대 위치 대응과 시험기 결과를 나란히 비교했습니까?

- 단일모드 APC 채널의 어댑터 방향을 제조사 설계서로 확인했습니까?

## 확인 문제와 정답

### 1. 부품 라벨에 Type B가 보이면 방식 B 채널입니까?

정답·해설: 아닙니다. 방식은 채널 전체의 조합이고 형식은 부품 하나의 이름입니다. 방식 A의 배열 구성에도 한쪽 끝에 Type B 코드가 들어갑니다.

### 2. 8심 병렬 응용에서 송신이 1–4, 수신이 9–12일 때 형식 C 트렁크가 맞지 않는 까닭은 무엇입니까?

정답·해설: 형식 C는 1번을 2번으로 보내 송신이 같은 송신 쪽 위치에 닿습니다. 이 응용은 1→12처럼 역순 대응이 필요합니다. 장비의 실제 송수신 배치는 사양서로 확인합니다.

### 3. U1이나 U2를 MPO끼리 잇는 배열 링크의 방식으로 정해도 됩니까?

정답·해설: 아닙니다. 이번에 확인한 TIA 요약은 U1과 U2의 듀플렉스 구현만 설명합니다. 배열 링크는 방식 A, B, C 중에서 설계서를 확인합니다.
