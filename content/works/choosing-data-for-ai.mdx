AI에 올릴 자료는 맡길 작업에 필요한 부분만 고르고, 그 자료를 해당 서비스로 보내도 되는지 확인한 뒤 준비합니다. AI 교육의 첫 실습에는 실제 개인정보나 기밀이 없는 가상 자료를 우선 쓰는 편을 권합니다. 이름을 지웠거나 학습 활용을 껐다는 이유만으로 원본 문서를 올려도 된다고 판단하지 않습니다.

이 글은 자료 선택과 실습 준비를 위한 실무 가이드입니다. 특정 고객사에서 실시한 교육이나 보안 심사 결과가 아닙니다. 2026년 10월 19일 확인한 공식 자료를 참고했으며, 아래 선택표와 실습 순서는 DMS.Labs의 교육 설계 제안입니다. 조직의 보안 규정과 계약, 적용 법률에 따른 검토를 대신하지 않습니다.

## 파일을 고르기 전에 작업을 좁힙니다

회의 메모에서 할 일을 추리는 실습을 생각해 보십시오. 담당자와 마감일을 찾아 표에 옮기는 연습이라면 실제 고객의 이름, 연락처, 계약 단가까지 필요하지 않습니다. 가상의 사람과 일정으로 만든 짧은 메모에도 담당자 누락이나 날짜 불일치 같은 판단 조건을 넣을 수 있습니다. 처음부터 원본 회의록 전체를 건넬 이유가 줄어듭니다.

교육 담당자는 결과물에서 확인할 행동부터 한 문장으로 적습니다. 예를 들어 메모에 적힌 할 일만 추리고, 없는 마감일은 미확인으로 남기는 작업입니다. 그 행동을 연습하는 데 쓰이지 않는 내용은 입력 후보에서 뺍니다. 자료를 줄여도 과제를 수행할 수 있는지 확인한 다음, 필요한 항목만 따로 만든 실습본에 옮깁니다.

[업무 설명서 한 장](/works/ai-skill-job-sheet)의 입력 칸에는 파일 이름뿐 아니라 허용된 자료의 범위를 적을 수 있습니다. 공개 문서 중 특정 절만 허용하는지, 사내 승인된 실습본만 쓰는지 명시하는 방식입니다. 원본을 읽을 권한과 외부 AI에 보낼 권한은 따로 확인합니다. 사내 공유 폴더에서 열리는 파일도 열람 가능 여부만으로 외부 전송을 허용할 수는 없습니다.

## 자료 선택표에는 무엇을 적습니까?

자료의 목적, 필요한 부분, 전송 허용 여부와 보관 조건을 함께 적습니다. 다음 표는 법적 등급표가 아니라 실습 준비용 분류 제안입니다. 실제 판단이 모호한 자료는 보류하고, 같은 학습 목표를 연습할 가상 자료로 바꿉니다.

| 자료 상태 | 실습 준비 방향 | 남길 확인 내용 |
| --- | --- | --- |
| 공개된 공식 설명서 | 필요한 절만 발췌하되 이용 조건 확인 | 출처, 판본, 사용 범위 |
| 처음부터 만든 가상 메모 | 실존 인물·사건이 섞이지 않았는지 점검 | 가상 자료 표시, 과제 조건 |
| 이름을 지운 업무 문서 | 다른 내용으로 사람이 드러나는지 재검토 | 식별 단서, 외부 전송 승인 |
| 고객·직원 개인정보나 계약상 기밀 | 승인된 처리 근거와 환경 확인 전 보류 | 담당 검토자, 보류 이유 |
| 비밀번호·인증 코드·비밀 키 | 교육용 입력에서 제외 | 실제 값을 넣지 않는 대체 방법 |

공개된 자료에도 이용 조건과 개인정보가 있을 수 있습니다. 외부에 보이는 문서라는 이유만으로 복제·재배포 권리나 모든 처리 권한을 얻는 것은 아닙니다. 실습에 필요한 짧은 부분을 고르고 출처를 남기며, 이용 조건이 불분명하면 별도로 만든 예시를 사용하십시오.

선택표를 원본 내용으로 채우지는 않습니다. 검토자가 어느 파일인지 찾을 수 있는 내부 식별자와 승인 상태만 남기고, 연락처나 비밀 키를 보류 사유에 그대로 복사하지 않습니다. 확인표 자체가 새로운 유출 경로가 되지 않도록 접근 범위도 정합니다.

## 이름만 지우면 올려도 됩니까?

이름을 지웠다는 사실만으로는 충분하지 않습니다. 직책, 특정 사건의 날짜, 드문 업무 이력이 함께 남으면 누군지 알아볼 가능성이 있습니다. 얼굴이나 연락처뿐 아니라 자유롭게 적은 메모의 문맥도 확인해야 합니다.

영국 개인정보 감독기관 ICO는 가명처리와 익명화를 구분합니다. 별도로 보관한 추가 정보와 연결해 사람을 알아볼 수 있는 가명정보는 여전히 개인정보라는 설명입니다. 이 지침은 영국 법체계에 관한 자료이며 현재 재검토 중이라는 안내가 있습니다. 여기서는 이름 치환을 익명화 완료로 오해하지 않기 위한 개념 구분으로 참고합니다. 한국 조직의 적법성을 이 설명만으로 판정하지 않습니다.

예를 들어 실제 직원 이름을 참가자 A로 바꿔도 특정 지점의 유일한 담당자라는 문장이 남을 수 있습니다. 이 예는 식별 단서를 설명하려는 가정입니다. 교육 담당자가 실제 직원 문서를 찾아 익명화를 시험하라는 뜻이 아닙니다. 첫 실습을 만들 때는 업무 형식만 참고해 독립적인 가상 문장을 작성하고, 실제 원문과 대응되는 변환표가 필요 없는 방향을 우선 검토합니다.

스프레드시트의 다른 시트, 문서의 주석과 변경 기록, 화면 캡처 가장자리도 점검 대상에 넣습니다. 화면에서 가린 글자가 복사되는지 확인하고 최종 업로드 파일을 다시 열어 보십시오. 이런 점검은 실무상 누락을 줄이기 위한 제안이며, 모든 형식의 숨은 정보를 완전히 제거했다고 보장하는 절차는 아닙니다.

## 학습에 안 쓰면 보관도 안 합니까?

학습 활용과 데이터 보관은 별도의 조건입니다. OpenAI는 비즈니스 제품과 API의 입력·출력을 기본적으로 모델 학습에 쓰지 않는다고 설명합니다. 한편 API 문서는 악용 모니터링 기록과 기능 제공을 위한 상태 저장을 구분하고, 기본 모니터링 기록은 예외 조건을 두고 최대 30일 보관한다고 안내합니다. 기능에 따라 별도 저장 조건도 있습니다.

이 설명을 모든 개인용 AI 계정이나 다른 회사 제품에 적용하면 안 됩니다. 같은 회사 서비스 안에서도 제품, 요금제, 기능과 설정을 확인해야 합니다. 보관하지 않는다는 특수 조건도 자동 적용된다고 가정하지 말고, 실제 조직과 기능에 해당하는지 확인하십시오. 이 글은 특정 계정의 계약이나 저장 설정을 조사한 결과가 아닙니다.

한국 개인정보보호위원회는 2026년 5월 19일 이용자용 생성형 AI 개인정보 보호 가이드 발간을 알렸습니다. 보도자료는 학습 활용 거부와 대화 기록 저장·삭제 설정, 업무 자료 입력, 외부 서비스 연동을 각각 확인할 문제로 다룹니다. 여기서는 해당 보도자료를 확인했으며 첨부 안내서 전체를 검토했다고 주장하지 않습니다.

교육용 도구를 정할 때에는 서비스 이름 옆에 실제 사용할 계정 종류, 업로드 기능과 연결 서비스를 적습니다. 자료가 처음 들어가는 AI뿐 아니라 이후 전달되는 자동화 도구와 저장소까지 범위를 잡습니다. 외부 연동이 붙었다면 원래 서비스의 약속만으로 연동 대상의 처리를 설명할 수 없습니다.

## 실습본은 어떻게 확인합니까?

실습본을 업로드하기 전에 사람이 최종 파일과 과제 조건을 대조합니다. 회의 메모 정리라면 메모에 없는 연락처를 요구하지 않는지, 가상의 날짜와 담당자가 서로 맞는지 살핍니다. 민감한 내용을 지우느라 과제의 의미까지 없어졌다면 원본을 더 넣기보다 가상 자료를 다시 작성하는 편을 검토합니다.

실습 결과의 품질도 따로 봅니다. 가상 자료가 단순하면 실제 업무의 예외를 충분히 시험하지 못합니다. 담당자 누락이나 서로 충돌하는 일정처럼 연습할 조건을 명시하고, 잘못된 답을 어떻게 판정할지 미리 적습니다. [AI 스킬 합격 기준](/works/ai-skill-acceptance-tests)은 입력을 준비한 뒤 결과를 확인하는 방법으로 이어집니다. 가상 실습에 통과했다고 실제 개인정보 처리가 승인되는 것은 아닙니다.

검토 기록에는 허용한 실습본의 판본과 사용 목적, 확인한 설정, 보류한 항목을 남깁니다. 원본이 바뀌거나 새로운 외부 연결을 붙이면 이전 승인 범위가 여전히 맞는지 다시 확인합니다. 실습 중 뜻하지 않은 실제 정보가 발견되면 추가 전송을 멈추고 조직의 사고 대응 절차를 따릅니다. 단순히 대화창에서 지웠다는 이유로 이미 전달된 모든 사본이 사라졌다고 보고하지 않습니다.

실습본을 만드는 과정도 조직이 허용한 환경 안에서 진행합니다. 외부 AI에 원본을 올려 놓고 개인정보를 지워 달라고 요청하면, 정리 전에 이미 원본을 전송한 셈입니다. 원본을 외부로 보낼 수 없는 상황이라면 그 처리 과정부터 외부 서비스에 맡기지 않습니다. 기존에 승인된 내부 도구와 수작업으로 준비하거나, 원본을 쓰지 않는 가상 자료를 선택하십시오.

가상 자료를 만들 때에는 실제 문장을 조금씩 바꾸는 방식과 처음부터 과제에 맞춰 쓰는 방식을 구분합니다. 특정 계약의 날짜와 금액만 바꾸어도 상대방이나 프로젝트를 알아볼 맥락은 남을 수 있습니다. 연습에 필요한 조건이 담당자 누락이라면, 실제 사건을 각색하는 대신 관련 없는 새 업무 상황에 그 조건을 넣는 편을 검토합니다. 만든 자료에도 실제 인물과 연결되는 내용이 없는지 사람이 확인합니다.

여럿이 듣는 교육에서는 참가자별 입력 범위도 맞춥니다. 강사가 가상 자료를 준비했더라도 참가자가 자기 업무 파일을 추가로 올리면 검토 범위가 달라집니다. 실습 안내에 허용한 파일과 추가 업로드를 보류할 조건을 적고, 화면 공유 중 다른 창이나 알림에 실제 정보가 나타나지 않는지도 살핍니다. 이 점검 역시 이미 승인된 화면과 파일만 대상으로 합니다.

교육 후 실습본과 결과를 누가 보관할지도 미리 정합니다. 수강생이 만든 결과에는 입력 일부가 다시 나타날 수 있으므로 공유 폴더와 제출물에도 같은 취급 기준을 적용합니다. 저장 위치와 보존 기간은 실제 조직 방침을 따르며 이 글에서 임의의 기간을 정하지 않습니다. 삭제 여부를 기록할 때에는 확인한 위치와 범위를 남겨, 다른 서비스의 사본까지 확인한 것으로 오해하지 않게 합니다.
